# نشان‌های برند دُنیش

سه هویت تصویری مستقل داریم و نباید با یکدیگر جایگزین شوند:

- برند مادر `donysh.ir`: فایل `donysh-wordmark.png` با نوشتهٔ لاتین `donysh` و SHA-256 برابر `38AEC9AA1984B2B03DFF58FEB25125C41D370D427D57EB6B25413404B8747B6F`؛ در سربرگ، پاورقی، favicon و بخش‌های عمومی صفحهٔ اصلی استفاده شود.
- دُنیش مالی: فایل `donysh-finance-logo.png` با نشان D و نمودار میله‌ای و SHA-256 برابر `4599AAE7CC8BD382E2BC3F4591FA58F6EF3FA6B6FE075EE894C3FA9B5C556E85`؛ `donysh-mark.png`، لوگوی Auth و تصاویر MAUI باید کپی باینری همین فایل باشند.
- دُنیش زندگی: فایل `donysh-life-logo.png` فقط برای سرویس زندگی استفاده شود.

در `donysh.ir` فقط کارت و پیش‌نمایش‌های مربوط به سرویس مالی از نشان مالی استفاده می‌کنند. صفحه‌های عمومی از لوگوتایپ برند مادر استفاده می‌کنند. در `finance.donysh.ir` نشان مالی کنار نام متنی «دُنیش مالی» نمایش داده می‌شود و اپ همراه نیز از همان نشان مالی استفاده می‌کند.

سازندهٔ آیکن MAUI خروجی‌های قبلی را در `obj` نگه می‌دارد. `scripts/Publish-MobileApk.ps1` پیش از ساخت Release فرمان `dotnet clean` را اجرا می‌کند تا APK منتشرشده تصویر تازه را داشته باشد. پیش از انتشار، آیکن تولیدشده در `obj/Release/net9.0-android/resizetizer/r/` و گواهی امضای APK را بررسی کنید. هر نسخهٔ جدید اندروید باید `ApplicationVersion` بزرگ‌تری داشته باشد.
