# دستیار برنامه‌ریزی زندگی

مسیر `/Ai` یک تب برای ساخت فعالیت و برنامهٔ هفتگی با کمک AI شخصی کاربر است. دنیش به مدل خارجی وصل نمی‌شود و روتین کاربر را دریافت نمی‌کند. کاربر روتین را در گفتگوی خودش توضیح می‌دهد، راهنمای آمادهٔ صفحه را کپی می‌کند، فایل JSON می‌گیرد و آن را در لایف بارگذاری یا به‌صورت متن وارد می‌کند.

## قرارداد JSON

```json
{
  "version": 1,
  "activities": [
    {
      "title": "مطالعه",
      "category": "یادگیری",
      "color": "#2563EB",
      "icon": "book",
      "weeklyHours": 5,
      "slots": [
        { "day": "Saturday", "start": "09:00", "durationMinutes": 60 }
      ]
    }
  ]
}
```

- روزها نام انگلیسی `DayOfWeek` هستند؛ ساعت ۲۴ ساعته `HH:mm` و شروع/مدت روی گام‌های ۳۰ دقیقه است.
- هر فعالیت عنوان یکتا، رنگ و نماد موجود در `ActivityCatalog`، هدف هفتگی ۰٫۵ تا ۱۶۸ ساعت و ۱ تا ۱۰ بازه دارد. حداکثر ۲۰ فعالیت و ۸۰ بازه پذیرفته می‌شود.
- ورودی حداکثر ۴۸هزار نویسه است. هر بازه می‌تواند تا ۲۴ ساعت طول بکشد و از نیمه‌شب عبور کند. بازه‌های هم‌زمان نیز مجازند و در تقویم کنار هم نمایش داده می‌شوند.

## مسیر ثبت

پیش‌نمایش هیچ داده‌ای ذخیره نمی‌کند. منبع JSON با Data Protection به شناسهٔ کاربر و مهلت ۳۰ دقیقه‌ای بسته می‌شود. کاربر می‌تواند هر فعالیت یا زمان را حذف و روز/ساعت/مدت زمان‌های باقی‌مانده را ویرایش کند. هنگام تأیید، سرور دوباره تمام انتخاب‌ها، مالکیت و نام‌های تکراری را بررسی می‌کند. فعالیت‌ها، هدف‌ها و الگوهای تکرارشونده در یک `SaveChanges` ثبت می‌شوند. تأیید دوباره به‌خاطر عنوان تکراری، فعالیت تازه نمی‌سازد.

## نگهداری

اگر قالب JSON، قوانین `ActivityCatalog` یا قواعد `WeeklyScheduleService` تغییر کرد، متن راهنمای `LifeAiPlanService.Prompt`، اعتبارسنجی همان سرویس و تست‌های `Donysh.Life.Tests` را با هم به‌روز کنید. تب در ناوبری دسکتاپ و موبایل `_Layout.cshtml` وجود دارد. تست Life مسیر پیش‌نمایش، ویرایش زمان، حذف فعالیت از انتخاب و جلوگیری از ثبت تکراری را پوشش می‌دهد.
