# IRANYekanX Pro

فایل فونت دارای مجوز را از بسته‌ای که خریداری کرده‌اید در این پوشه قرار دهید:

```text
IRANYekanXVFaNumVF.woff2
```

مسیر آن داخل آرشیو رسمی معمولاً این است:

```text
IRANYekanX Pro/Farsi numerals/Variable Font/Webfonts/IRANYekanXVFaNumVF.woff2
```

پس از کپی فایل، Docker image را دوباره build کنید.
